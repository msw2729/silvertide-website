CONSENT DESIGN
Basic consent mode globally. The Google script is not inserted before opt-in; rejection does not send cookieless pings. Equal Accept/Reject buttons, bilingual copy, a privacy-notice link and a persistent settings control. Choice is saved locally for 180 days. If storage is blocked the choice applies only to the current page. Withdrawal disables GA, clears accessible GA cookies and reloads without the tag. Withdrawal in another tab also stops this tab. Advertising consent remains denied.

EVENTS
Campaign attribution is explicit: accept one utm_source from google, bing, linkedin, facebook, instagram, youtube, newsletter and one utm_medium from organic, cpc, ppc, email, referral, social, paid_social, display, affiliate (case-insensitive). Both must match before either is used. Duplicated source/medium parameters reject the pair. Campaign names require an exact reviewed public label in config.campaignNames (empty by default); unknown names are excluded. A slug-format check alone is not a personal-data filter, so arbitrary campaign names are never accepted. No utm_term, utm_content, utm_id, click IDs or arbitrary query values are forwarded. Explicit blank campaign overrides prevent raw UTM fallback. These manual campaign overrides follow the official GA4 configuration reference. Existing referrer origins preserve normal referral/search source signals.
Attribution limits: non-allowlisted campaigns lose their manual tags; traffic may fall back to referrer/direct. Consent granted only after leaving a tagged landing page loses that landing campaign (no pre-consent storage). No ad-click auto-tagging or cross-device attribution is promised. Allowlisted values are user-controlled labels, not authenticated evidence of traffic origin. Mocked tests verify the supplied Google configuration, not final GA reporting or Google's internal tag behavior; validate real reports after approved activation.
Required addition to the pending privacy notice (EN): "With your permission, we also measure traffic sources using referring website origins and a limited set of public campaign labels. We exclude arbitrary URL query values and do not send inquiry form contents to Analytics."
Required addition to the pending privacy notice (ES): "Con tu permiso, también medimos las fuentes de tráfico mediante el origen de los sitios web de referencia y un conjunto limitado de etiquetas públicas de campaña. Excluimos los valores arbitrarios de los parámetros de las URL y no enviamos a Analytics el contenido del formulario de consulta."
The consent banner explicitly mentions traffic sources / fuentes de tráfico. The approved notice includes this description.
- Exactly one explicit page_view per consented document load; send_page_view:false disables config's automatic pageview. Referrer is reduced to origin (or a known internal route). Page location uses a known clean path without query/hash; title is a fixed page label. Arbitrary URL paths and form data never enter custom events.
- GA's automatic session/user engagement provides engagement time after consent. Custom scroll_depth fires once at 90%; Enhanced Measurement scroll must stay off.
- internal_navigation records a fixed destination page label and page/section type. language_switch records only en/es. outbound_click records only destination hostname. email_click records no recipient, subject or body.
- generate_lead records only form_id, fixed page_id and site_language after the existing Formspree handler receives response.ok. It does not fire on native validation, server/network errors or repeated submissions. Success without consent is not stored/replayed after later consent.
- No names, emails, company names, phone numbers, products, quantities, free text or other field values are read by analytics code. No user ID or user properties are set. Actual Formspree delivery still requires separate inbox confirmation.
